# v0.6 cross-platform test checklist

Run this checklist with disposable Markdown folders before relying on the
release for active manuscripts. Repeat the core pass on macOS, Linux amd64, and
the physical 2 GB Raspberry Pi 4.

## Prepare

1. Create two projects with Markdown files in their roots and nested folders.
2. Add at least one ordinary Markdown file to Inbox.
3. Keep both projects open in the sidebar and pin one of them.
4. Confirm edits are saved before beginning move or Trash tests.

## Navigation

- Search for text found only in Inbox, then only in each open project. Confirm
  that every result shows its origin and opens the correct sheet without
  closing another project.
- Press Command+P on macOS or Control+P on Linux. Type a title, use Up/Down,
  open it with Enter, and close the switcher with Escape.
- Open several sheets, then reopen the switcher with an empty query. Confirm
  recent sheets lead the results.
- Favorite a sheet, close its project, and confirm the favorite remains in the
  switcher and can reopen the project. Remove the favorite afterward.
- Restart the app. Confirm open projects, pinned projects, recent sheets, and
  favorites restore according to their settings without changing any Markdown
  file.

## Multi-selection

- Enter Select mode, choose sheets from two folders in the same source library,
  and confirm the selected count remains accurate while changing folders.
- Use Command+A or Control+A to select all visible sheets. Press Escape and
  confirm selection mode closes without moving or deleting anything.
- Move several selected sheets into another open project. Confirm every file is
  readable at the destination and absent from its old location.
- Move several sheets to Trash, restore one, then permanently empty only the
  disposable test items.
- Export a selection as DOCX, PDF, and EPUB. Confirm only selected sheets appear
  and that their order matches the chosen alphabetical or creation-date order.
- Create a same-name destination collision and repeat a batch move. Confirm the
  app reports partial progress, already completed moves remain intact, and
  unprocessed sheets stay selected.

## Existing safety and editor behavior

- Edit a file externally while its project is open and clean; confirm the app
  refreshes it. Repeat while the editor is dirty and confirm the app does not
  overwrite either version silently.
- Switch between Write and Preview, test spelling underlines and Writing Focus,
  and type continuously for at least one minute. Confirm typing remains
  responsive and autosave completes after the pause.
- Run a manual universal sync between two disposable copies. Confirm conflicts
  are preserved as additional Markdown files and no excessive-delete guard is
  bypassed.
- Check for an application update from Writer (Aa). On the Raspberry Pi, also
  run Super+Space, open Updates, and confirm the signed APT path is available.

Record the application version, operating system, and any failed step with the
exact sheet paths involved.
